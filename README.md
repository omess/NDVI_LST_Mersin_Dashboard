# NDVI & LST Mersin Dashboard

Interactive dashboard visualizing NDVI (Normalized Difference Vegetation Index) and Land Surface Temperature analysis for Mersin, Turkiye.

## Overview

This dashboard provides interactive visualizations of vegetation health (NDVI) and land surface temperature (LST) across Mersin, Turkiye, derived from Landsat 8 satellite data.

## Tech Stack

- Python
- Google Earth Engine
- Landsat 8
- Dashboard framework
- QGIS
